# 🚗 NxtPark

**NxtPark** is a futuristic, event-focused parking companion built with React.

Explore upcoming events, scroll through interactive listings, and manage your account — all through a sleek, dark-themed interface designed for modern web and mobile experiences.

---

## ✨ Features

- 🔮 Clean, dark-mode UI with futuristic styling
- 🗺️ Interactive embedded map
- 🎟️ Side-scrolling event cards with auto-loop
- 📅 Recently hosted events for credibility
- 👤 Account settings with flat UI components
- 📱 Mobile-friendly tab navigation with glowing indicator

---

## 📦 Built With

- React
- JavaScript (ES6+)
- Inline CSS styling (minimal dependencies)
